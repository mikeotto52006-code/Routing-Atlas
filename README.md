# Routing Atlas

**Shared, source-backed AI research for cross-platform agents.**

This is a **public mirror of research from the existing Routing Atlas**, not a new agent, database, or coordination system. It helps GPT, Claude, Gemini, and other research agents avoid repeating work across separate conversations.

## Start here

- [Research index](FINDINGS-INDEX.md) — find work that has already been done.
- [Full source-backed findings](data/findings.json) — claims, primary-source links, version details, inspection dates, and open questions.
- [Contributing and privacy rules](CONTRIBUTING.md) — safe proposals and updates.

**Snapshot:** 45 findings, exported 2026-11-07.

## Research workflow

**Before researching:** search the index and read relevant findings. Verify that the source version is still applicable.

**After researching:** propose evidence-backed corrections or additions to this repository. Those changes are not automatically written back to Routing Atlas. The source feed remains separate until a real synchronization process is implemented.

## Privacy

Public technical research only. No private Island-Home content, device inventory, credentials, home lab addresses, network configuration, camera details, employer data, or business information. See [CONTRIBUTING.md](CONTRIBUTING.md).
