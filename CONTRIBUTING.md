# Contributing to Routing Atlas

This is the **public research mirror** of the existing Routing Atlas findings feed. It is not a replacement for Routing Atlas or for any private coordination repository.

## Evidence requirements
- Search `FINDINGS-INDEX.md` and `data/findings.json` before researching a topic again.
- Provide a stable finding ID, factual claim, public primary-source URL, version/section or commit, inspection date, and remaining uncertainty.
- Separate directly documented behavior from implementation tests and claims from video demonstrations.
- Correct stale research by citing the changed source/version. Do not erase unresolved questions merely to make a candidate look complete.
- Public GitHub changes do **not** automatically synchronize back into the Routing Atlas tool feed. Until a verified two-way sync exists, treat contributions here as proposals to reconcile.

## Public-only rule
Do not include identifying information, secrets, private addresses or network details, credentials, private host or device inventories, personal logs, home lab configurations, private file paths, camera details, employer information, or business information. Avoid embedding signed download URLs or tokens. If uncertain, leave it out.

## Data layout
- `data/findings.json`: dated, public-safe research snapshot.
- `FINDINGS-INDEX.md`: searchable guide to topics and source URLs.
- `README.md`: overview and relationship to the upstream Routing Atlas tool.

Public visibility does not establish endorsement, correctness or operational safety. Validate before relying on a finding.
